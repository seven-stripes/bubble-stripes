# Bubble Stripes — privacy policy

This repository exists for one reason: Google Play requires every app to
publish a privacy policy at a public URL.

`index.html` is the current policy (from 25 September 2026: the date check -
the game asks a Google server for the date so the daily challenge streak and
the lives stay fair - plus gameplay statistics by Google Analytics for
Firebase, rewarded ads by Google AdMob and the in-app update check by Google
Play). `2026-09-22.html` is the previous one, from before the date check,
`2026-09-15.html` the one from before statistics, `2026-09-14.html` the one
from before the update check, and `2026-09-07.html` the one from before ads. All are served by GitHub Pages. No
game code lives here; the game itself is in a private repository.

**Published at:** see the Pages URL in this repository's settings.
