# Bubble Stripes — privacy policy

This repository exists for one reason: Google Play requires every app to
publish a privacy policy at a public URL.

`index.html` is the current policy (from 14 September 2026, with rewarded
ads by Google AdMob). `2026-09-07.html` is the previous one, from before ads.
Both are served by GitHub Pages. No game
code lives here; the game itself is in a private repository.

**Published at:** see the Pages URL in this repository's settings.
